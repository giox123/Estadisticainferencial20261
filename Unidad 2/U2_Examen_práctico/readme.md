# DESCRIPCIÓN DE LA BASE DE DATOS

La base de datos **Diabetes Prediction Dataset** contiene información de 100,000 registros de personas y está diseñada para analizar los factores relacionados con la presencia de diabetes. Cuenta con 9 variables que incluyen datos personales, características físicas, antecedentes médicos y niveles de glucosa en la sangre.

Su principal objetivo es identificar patrones y relaciones entre factores como la edad, el género, el índice de masa corporal (IMC), la hipertensión, las enfermedades cardíacas, los antecedentes de tabaquismo y los niveles de hemoglobina glucosilada (HbA1c) y glucosa en sangre, para determinar si una persona presenta diabetes.

La variable principal es **diabetes**, que indica si la persona tiene o no esta enfermedad. El valor 0 representa que no tiene diabetes y el valor 1 representa que sí tiene diabetes.

Esta base de datos es útil para realizar análisis estadísticos, identificar factores de riesgo y desarrollar modelos de predicción mediante técnicas de análisis de datos y aprendizaje automático.

## CARACTERÍSTICAS DE LA BASE DE DATOS

- **Nombre:** Diabetes Prediction Dataset.
- **Número de registros:** 100,000.
- **Número de variables:** 9.
- **Formato:** CSV.
- **Tipo de información:** Datos personales y médicos.
- **Variable objetivo:** Diabetes.

## VARIABLES QUE CONTIENE

1. **Gender:** Género de la persona.
2. **Age:** Edad de la persona.
3. **Hypertension:** Indica si presenta hipertensión.
4. **Heart_disease:** Indica si tiene alguna enfermedad cardíaca.
5. **Smoking_history:** Historial de consumo de tabaco.
6. **BMI:** Índice de masa corporal.
7. **HbA1c_level:** Nivel de hemoglobina glucosilada.
8. **Blood_glucose_level:** Nivel de glucosa en la sangre.
9. **Diabetes:** Indica si la persona presenta diabetes.

## CONCLUSIÓN

La base de datos permite estudiar los principales factores relacionados con la diabetes y conocer cómo determinadas características físicas y médicas pueden influir en su aparición. Además, facilita la realización de análisis y la creación de modelos que ayuden a predecir la presencia de esta enfermedad.
