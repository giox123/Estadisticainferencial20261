# Descripción de la base de datos

La base de datos contiene información sobre **2,004 propiedades en venta en Toluca, Estado de México**. Su objetivo es organizar los datos de diferentes viviendas para analizar sus características y precios.

La base de datos está compuesta por cinco variables principales: **ubicación**, que indica dónde se encuentra la propiedad; **área**, que representa el tamaño del inmueble; **baños**, que indica la cantidad de baños; **habitaciones**, que señala el número de habitaciones; y **precio**, que representa el valor de venta de la propiedad.

Esta información permite realizar análisis estadísticos para identificar la relación entre las características de las viviendas y sus precios, comparar propiedades y estudiar qué factores podrían influir en su valor de venta. Asimismo, los datos pueden utilizarse para elaborar tablas, gráficas y modelos de regresión que faciliten la interpretación de la información inmobiliaria.

Es importante considerar que algunos registros pueden contener datos faltantes, por lo que se deben revisar antes de realizar los análisis estadísticos.
